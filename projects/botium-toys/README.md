# Botium Toys — Security Controls Review

**Context:** Google Cybersecurity Certificate coursework / simulation.  
**Status:** Written recommendations complete; checklist selections unverified.

## Objective

Review the fictional toy business’s controls and compliance needs. The available checklist contains recommendations about access, protection, detection, and recovery.

## Recommendations recorded in the source

Botium Toys should prioritize implementing least privilege, separation of duties, encryption, an intrusion detection system, secure password management, critical data backup and a disaster recovery plan. The company should also improve asset inventory and classification and strengthen controls around PII/SPII and cardholder data to improve PCI DSS and GDPR compliance. These will significantly improve the organization's overall security posture.
